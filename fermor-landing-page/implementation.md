# Build a Complete Fermor Personal Finance Website

Build a polished, modern, responsive website for **Fermor**, an India-focused personal finance platform.

## 1. Fermor Brand & Core Positioning

### Brand
![alt text](image.png) logo use this
**Fermor**

### One-line positioning

**Make money management easier, one decision at a time.**

### Core description

Fermor is a personal finance platform built for India. We make free, accurate financial calculators that help people understand the real math behind everyday money decisions.as services in finanical investments support

Core tools include:

* EMI Calculator
* SIP Returns Calculator
* FD Interest Calculator
* Income Tax Calculator
* Salary Take-Home Calculator
* Loan Calculator
* Investment Calculators
* Savings Calculators
* Retirement Calculator
* Other practical Indian personal-finance calculators

Every calculator's math runs entirely in the user's browser.

**Important privacy message:**

The numbers users enter into calculators are never sent to Fermor's servers simply to calculate a result.

Creating an account is optional and is only required if the user wants to save calculations and access them later.

Fermor keeps its tools free through advertising and affiliate partnerships.

The website should communicate this clearly without making exaggerated financial or investment promises.

**Orange**
→ primary brand/action color

**Green**
→ growth, savings, positive financial outcomes

**White**

**Dark charcoal**
→ text and important information

Avoid excessive dark-mode fintech aesthetics.

Avoid cryptocurrency-style visuals.

Use subtle gradients only where they improve the design.

The final website should immediately communicate:

**Fermor = Personal finance made simple for India.**

The visitor should understand within 5 seconds:

1. What Fermor is
2. Who it is for
3. What problems it solves
4. Why the calculators are useful
5. That the calculators are free
6. That calculator inputs stay in the browser
7. How Fermor can help with everyday money management
8. How to start using it

The final experience should feel like a combination of:

**Modern fintech + personal finance education + intelligent financial dashboard + calculator platform**

—not a traditional banking website.

Prioritize clarity, trust, simplicity and beautiful financial data visualization over unnecessary visual complexity.
